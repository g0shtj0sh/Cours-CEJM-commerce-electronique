# POINT : conformité juridique, l'antisèche de la présentation

Site : https://cours-cejm-commerce-electronique.vercel.app

Pour chaque consigne : où cliquer, et quoi dire en une phrase.

## Le fil de la démonstration (3 minutes)

1. **Accueil** : la marque, le produit, le prix TTC.
2. **Montres > une fiche** : l'offre complète.
3. **Acheter > Passer commande** : les coordonnées et la case décochée.
4. **Vérification** : les deux clics, puis la confirmation.
5. **Pied de page** : mentions légales, CGV, marque.

## Attention : 3 écarts entre les notes de cours et la loi

Le site suit la loi. Si le prof pose la question :

1. **Remboursement.** Les notes disent « 15 jours de plus ». L'article L221-24 du Code de la consommation dit **14 jours** après l'information de la rétractation. Le site indique 14 jours, donc il respecte aussi la limite des notes.
2. **Produits de luxe.** Les notes les citent comme exception. Ils ne figurent pas dans la liste de l'article L221-28. Le site le dit simplement : le prix ou la rareté d'une montre ne retirent pas le droit de rétractation.
3. **Rétractation en magasin.** Le droit existe en cas de démarchage, c'est-à-dire pour un contrat conclu hors établissement.

## Ce qui est fictif

Le site le dit dans son pied de page : la société, ses identifiants, le médiateur, les numéros de dépôt et les titres de propriété industrielle sont inventés. Aucun paiement n'a lieu, aucun e-mail n'est envoyé et les données saisies restent dans le navigateur. Seul l'hébergeur est réel.
